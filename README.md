# 🐳 Docker Templates

This repository contains ready-to-use Docker Compose templates for common self-hosted services.

## Available Templates
- [Portainer](./portainer)
- [MinIO](./minio)
- [PostgreSQL](./postgresql)
- [RabbitMQ](./rabbitmq)

Each directory contains:
- `docker-compose.yml`
- `.env.example`
- `README.md` with setup instructions
